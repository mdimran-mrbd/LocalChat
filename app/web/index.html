      About LocalChat

      LocalChat
      A private, zero-install team chat for your LAN.

      One small native binary. No cloud. No accounts. No telemetry. End-to-end encrypted direct messages.

      When enabled, this app checks GitHub Releases from the host browser and shows an update notice. Nothing installs or restarts until you choose Update now. No chat messages or personal data are sent.

      What's new — Version 3.0.123 · Build 123

      Chat information, profile/settings, channel/group management, and Windows release improvements.

      Chat and shared content
      • Added information panels for private and group chats.
      • Improved shared Media, Links, and Files counts, previews, and item listings.
      • Kept chat links clickable and supported links in channel descriptions.
      Profiles and settings
      • Edit usernames and designations; usernames must be unique.
      • Upload a profile picture or choose a predefined avatar.
      • Manage appearance, notifications, password changes, and logout from Settings.
      Channels, groups, and messaging
      • Edit channel names and descriptions, including links in descriptions.
      • Use group-wide @all mentions.
      • Improved reply, forward, reaction, message-toolbar, and pinned-message interactions.
      Administration and reliability
      • Improved admin visibility of persisted historical user accounts.
      • Added database migration support and Rust tests in CI.
      • Embedded the Windows app icon and published a SHA-256 checksum.
      Known limitation — HTTPS

      On private networks, browsers may still show ERR_CERT_AUTHORITY_INVALID until the LocalChat CA certificate is trusted on each connecting device. See the LAN HTTPS trust guide; do not bypass unverified certificate warnings.
